# Fly Bird Ultra

> 单文件 HTML5 管道飞行休闲游戏 ｜ 由 萝卜头开发团队 开发

一款完全离线、单文件实现的网页小游戏开源项目。全部代码、美术、音效与存档数据都封装在**一个 `.html` 文件**内，无任何外部图片、音频、脚本或字体依赖。玩法参考了经典 Flappy Bird，但全部代码、美术素材与音效均为萝卜头开发团队的原创成果。

当前版本：**v8.50.0**

---

## 快速开始

本仓库为**开源代码仓库**，仅作源码展示、学习与交流用途，不提供在线游玩，也不以游戏运营或分发为目的。仓库内容可直接 fork、查看与修改源码。

---

## 玩法

- 点击/触摸屏幕让小鸟扇翅上升，松开自然下落；
- 穿过萝卜橙管道，每穿过一对得 1 分；
- 撞击管道或落地即失败；
- 难度随得分递增（管道速度逐渐加快）。

## 技术说明

- **形态**：单文件 HTML5（CSS 内联、JS 内联、贴图 base64 内嵌），无前端框架、无构建工具；
- **渲染**：原生 Canvas 2D，`requestAnimationFrame` 主循环，帧率自适应（低配降帧）；
- **音频**：Web Audio API 本地合成音效与循环 BGM（节日专属旋律表）；
- **存储**：`localStorage` 持久化，金币 / 水晶数值经浮点加密；
- **兼容**：ES5 语法，兼容老款机型与低版本浏览器，三档画质适配低配设备；
- **联网**：仅天气背景按需读取公共天气 / 定位接口（离线自动回退），游戏本身无联网服务、无充值、无用户间交互。
